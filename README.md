### 🤖 Foodpanda APAC Customer Feedback Analysis (V2 — LLM Aspect Extraction)
> Python · pandas · google-genai (async) · Gemini 2.5 Flash Lite · Ollama (Llama 3.1) · Tableau

LLM-based aspect extraction on 279,723 foodpanda reviews across 9 APAC markets (Pakistan, Malaysia, Bangladesh, Taiwan, Singapore, Myanmar, Laos, Cambodia, Hong Kong). Designed a 6-aspect taxonomy separating platform-controllable complaints from vendor-side and non-actionable feedback. Iterated 5 prompt versions locally on Llama 3.1 8B before running production through the google-genai API for USD 24. Validated via blind hand-labeling on a held-out Singapore sample (0.82 recall). Built an interactive 5-tab Tableau Story with dual-view heatmaps and an adjustable-threshold restaurant watchlist. *Completed May 2026.*

### 🍜 Foodpanda APAC Customer Feedback Analysis (V1 — Keyword Frequency)
> Python · pandas · langdetect · jieba · Tableau

Multilingual keyword-frequency analysis of 4.6M+ foodpanda customer reviews across 11 APAC markets. Surfaced "small portions" as the APAC-wide #1 complaint (including colloquial Malay variants like "kecik") and identified a persistent 1.45-point quality gap between food rating (3.33) and rider rating (4.78). Caught and fixed a ~538k-record Traditional Chinese misclassification bug that would have invalidated Taiwan's analysis. *Completed April 2026.*

### 🛒 Olist E-Commerce Delivery Performance Analysis
> Python · pandas · SQL · BigQuery · Tableau

End-to-end analysis of 110,000+ orders across 27 Brazilian states and 70+ product categories. Engineered delivery performance features across 5 SQL analyses spanning state, category, seasonal, and review-score dimensions. Identified northeastern Brazil as an underserved logistics region (18–21% late vs 6.6% national avg) and quantified delivery impact on customer satisfaction (review scores drop from 4.2 to 2.3 when an order arrives late). *Completed April 2026.*
